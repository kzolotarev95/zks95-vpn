# Административная панель

Панель реализована по адресу `/admin` в Next.js-приложении `apps/web`. Общий API `/api/v1/admin`, отдельная административная сессия, обязательная TOTP 2FA и RBAC. Отдельный frontend-контейнер пока не требуется.

Разделы: сводка, пользователи, заказы, подписки, тарифы, Telegram-бот, аудит. Публичного создания администраторов нет. [Создание администратора и подключение бота](../../docs/ADMIN.md).
