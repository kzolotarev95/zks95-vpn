# Административная панель

Панель реализована по адресу `/admin` в Next.js-приложении `apps/web`. Общий API `/api/v1/admin`, отдельная административная сессия и RBAC; TOTP 2FA подключается для отдельных администраторов. Отдельный frontend-контейнер не требуется.

Разделы: сводка, пользователи, заказы, подписки, тарифы, VPN-панели 3x-ui / Remnawave, Telegram-бот, аудит. Публичного создания администраторов нет. [Создание администратора, подключение панели и бота](../../docs/ADMIN.md).
