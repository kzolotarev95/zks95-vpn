# Telegram Bot

aiogram 3 worker: `python -m app.bot`, контейнер `bot`. Всё состояние читает и изменяет через Backend API без доступа к PostgreSQL. Без включённой конфигурации остаётся в ожидании.

Токен вводится SuperAdmin в `/admin` → Telegram-бот, проверяется через getMe / getWebhookInfo и хранится зашифрованным. Настройки подхватываются без ручного перезапуска. Один токен — один polling worker; существующий сторонний webhook автоматически не удаляется.

Работают /start, анимированная карточка приветствия, inline-меню, кнопка Mini App, аккаунты, тарифы, идемпотентные заказы, подписки, Telegram Stars, статистика заказов, контакт поддержки и привязка web-аккаунта. После successful_payment бот подтверждает заказ через API и запускает выдачу VPN. Локации, устройства и реферальные начисления подключаются по мере наполнения панели.

Код: [backend/app/bot.py](../../backend/app/bot.py). [Настройка](../../docs/ADMIN.md).
