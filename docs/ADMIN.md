# Администратор и Telegram

## Обновление с первой версии

Первое обновление добавляет ключ шифрования и сервисный ключ бота. Сначала получите новый скрипт, затем запустите обновление. Для пути `/opt/zks95-vpn`:

```bash
cd /opt/zks95-vpn
sudo git -c safe.directory=/opt/zks95-vpn pull --ff-only
sudo python3 scripts/ensure-secrets.py
sudo bash scripts/update.sh
```

`ensure-secrets.py` добавляет только отсутствующие / пустые ключи, не меняет и не выводит непустые значения. Не удаляйте APP_ENCRYPTION_KEY: без него нельзя расшифровать TOTP-секреты и токен Telegram. Сохраняйте `.env` вместе с независимыми резервными копиями базы. Последующие обновления: `sudo bash scripts/update.sh`. При новой установке ключи создаются автоматически.

## Первый администратор

Замените email своим. Для production добавляйте `-f docker-compose.yml -f docker-compose.prod.yml` после `docker compose` во всех командах.

```bash
sudo docker compose exec api python -m app.cli admin-create --email admin@example.com
```

Нужен интерактивный терминал: не добавляйте `-T`. Для нового аккаунта команда попросит пароль минимум из 12 символов и повтор. Для существующего аккаунта — текущий пароль; он не изменится. Общего пароля admin/admin нет.

Команда покажет ключ TOTP только в текущем интерактивном терминале. Добавьте его как временной код в Google Authenticator, 2FAS, Aegis или другое TOTP-приложение: issuer `ZKS95 VPN`, account — указанный email. Введите полученный шестизначный код. Если код не совпал, изменения не сохраняются. На VPS и телефоне должно быть верное время.

Панель: `/admin`; при SSH-туннеле — http://localhost:8080/admin. Для входа нужны email, пароль и текущий код 2FA. Сессия действует 30 минут; использованный код нельзя повторно применить для входа.

Восстановление потерянной 2FA через доверенный SSH-доступ и текущий пароль:

```bash
sudo docker compose exec api python -m app.cli admin-create --email admin@example.com --reset-mfa
```

Это заново привяжет аутентификатор и отзовёт административные сессии. Роль по умолчанию SuperAdmin; для других администраторов используйте `--role Admin`, `--role Support` или `--role Finance`. Восстанавливая другую роль, укажите её явно.

## Разделы панели

| Раздел | Возможности |
| --- | --- |
| Обзор | Пользователи, Telegram, заказы, активные подписки, сумма оплаченных заказов |
| Пользователи | Поиск, блокировка / разблокировка; блокировка отзывает сессии |
| Тарифы | Создание, изменение цены, срока, числа устройств и видимости |
| Заказы | Общая история; цену / статус оплаты нельзя подменить через панель |
| Подписки | Общий список и отзыв действующей подписки |
| Telegram | Токен, включение / выключение, поддержка и живой статус worker |
| Аудит | Входы, тарифы, блокировки, отзыв подписок, настройка Telegram |

Telegram доступен только SuperAdmin. Admin управляет пользователями, тарифами и подписками. Support читает пользователей / заказы / подписки; Finance — тарифы / заказы / подписки. Все роли видят сводку. Административные аккаунты создаются только CLI-командой.

## Подключение бота

1. Создайте бота в официальном [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. В панели откройте Telegram-бот, введите токен, при необходимости username поддержки и включите переключатель.
3. Нажмите «Сохранить настройки». Backend проверит токен; worker подхватит его в течение 5–20 секунд. Токен не отправляйте в Git или чат.
4. Дождитесь статуса подключения, откройте ссылку `@ваш_бот` и нажмите `/start`.

Для существующего аккаунта сайта сначала используйте в личном кабинете «Подключить Telegram» → персональную ссылку. Она действует 5 минут и один раз. Обычный `/start` без ссылки создаёт отдельный Telegram-аккаунт. Уже существующие разные аккаунты автоматически не объединяются.

Старый webhook автоматически не удаляется. Сначала остановите прежний сервис и отключите webhook. При конфликте polling панель покажет ошибку. Проверка сервисов:

```bash
sudo bash scripts/health-check.sh
sudo docker compose ps
sudo docker compose logs --tail=50 bot
```

Меню, аккаунты, тарифы, заказы и просмотр подписок реализованы. ЮKassa, Stars, VPN-конфигурации, реальные локации, трафик и реферальные начисления ещё не подключены. Заказ не активирует доступ. Live-соединение Telegram нужно проверить на вашей VPS после настройки настоящего токена.
