# Администратор и Telegram

## Обновление с первой версии

Первое обновление добавляет ключ шифрования и сервисный ключ бота. Сначала получите новый скрипт, затем запустите обновление. Для пути `/opt/zks95-vpn`:

```bash
cd /opt/zks95-vpn
sudo git -c safe.directory=/opt/zks95-vpn pull --ff-only
sudo python3 scripts/ensure-secrets.py
sudo bash scripts/update.sh
```

`ensure-secrets.py` добавляет только отсутствующие / пустые ключи, не меняет и не выводит непустые значения. Не удаляйте APP_ENCRYPTION_KEY: без него нельзя расшифровать TOTP-секреты и токен Telegram. Сохраняйте `.env` вместе с независимыми резервными копиями базы. Последующие обновления: `sudo bash scripts/update.sh`. При новой установке ключи создаются автоматически.

## Первый администратор

Замените email своим. Для production добавляйте `-f docker-compose.yml -f docker-compose.prod.yml` после `docker compose` во всех командах.

```bash
sudo docker compose exec api python -m app.cli admin-create --email admin@example.com
```

Нужен интерактивный терминал: не добавляйте `-T`. Для нового аккаунта команда попросит пароль от 5 до 128 символов и повтор. Для существующего аккаунта — текущий пароль; он не изменится. При автоматической установке создаётся первый доступ `admin/admin`; после входа его нужно сменить. Ручная команда также принимает пароль от 5 до 128 символов.

Команда покажет ключ TOTP только в текущем интерактивном терминале. Добавьте его как временной код в Google Authenticator, 2FAS, Aegis или другое TOTP-приложение: issuer `ZKS95 VPN`, account — указанный email. Введите полученный шестизначный код. Если код не совпал, изменения не сохраняются. На VPS и телефоне должно быть верное время.

Панель: `/admin`; при SSH-туннеле — http://localhost:8080/admin. Для первого входа используйте логин `admin`, пароль `admin`, поле 2FA оставьте пустым. Если администратор уже был создан раньше, его данные сохраняются. Для аккаунта с включённой 2FA нужен текущий код аутентификатора. Сессия действует 30 минут; использованный код нельзя повторно применить для входа.

Восстановление потерянной 2FA через доверенный SSH-доступ и текущий пароль:

```bash
sudo docker compose exec api python -m app.cli admin-create --email admin@example.com --reset-mfa
```

Это заново привяжет аутентификатор и отзовёт административные сессии. Роль по умолчанию SuperAdmin; для других администраторов используйте `--role Admin`, `--role Support` или `--role Finance`. Восстанавливая другую роль, укажите её явно.

## Разделы панели

| Раздел | Возможности |
| --- | --- |
| Обзор | Пользователи, Telegram, заказы, активные подписки, сумма оплаченных заказов |
| Пользователи | Поиск, блокировка / разблокировка; блокировка отзывает сессии |
| Тарифы | Создание, изменение цены в рублях, цены Telegram Stars, срока, числа устройств и видимости |
| VPN-панели | Подключение 3x-ui / Remnawave, проверка, назначение панели тарифу |
| Заказы | Общая история; цену / статус оплаты нельзя подменить через панель |
| Оплата | Shop ID и секрет ЮKassa, фискализация, статусы ЮKassa / Stars и возвраты |
| Подписки | Общий список и отзыв действующей подписки |
| Telegram | Токен, включение / выключение, поддержка и живой статус worker |
| Аудит | Входы, тарифы, блокировки, отзыв подписок, настройка Telegram |

Telegram доступен только SuperAdmin. Admin управляет пользователями, тарифами, оплатой и подписками. Support читает пользователей / заказы / подписки; Finance — тарифы / заказы / оплату / подписки. Все роли видят сводку. Административные аккаунты создаются только CLI-командой.

## Подключение 3x-ui или Remnawave

Откройте **VPN-панели** и добавьте подключение. Секрет панели шифруется в базе и повторно не показывается.

- **3x-ui:** укажите URL панели, API-токен из `Settings → Security → API Token`, ID одного или нескольких inbound и публичный URL подписок (`https://panel.example/sub`). Современный API использует `/panel/api/clients/*`; Legacy оставляйте только для VLESS/VMess и одного inbound.
- **Remnawave:** укажите URL API, API-токен и UUID хотя бы одного internal squad. Платформа использует `/api/users`, сохраняет настоящий `subscriptionUrl` и синхронизирует срок и трафик.

После проверки панели откройте **Тарифы** и назначьте её тарифу. Новый заказ сохраняет назначенную панель. После подтверждённой оплаты общий Billing service создаёт клиента в назначенной панели и сохраняет ссылку подписки. Если панель временно недоступна, заказ остаётся оплаченной записью и его можно повторно выдать после восстановления панели.

## Подключение бота

1. Создайте бота в официальном [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. В панели откройте Telegram-бот, введите токен, при необходимости username поддержки и включите переключатель.
3. Нажмите «Сохранить настройки». Backend проверит токен; worker подхватит его в течение 5–20 секунд. Токен не отправляйте в Git или чат.
4. Дождитесь статуса подключения, откройте ссылку `@ваш_бот` и нажмите `/start`.

Для существующего аккаунта сайта сначала используйте в личном кабинете «Подключить Telegram» → персональную ссылку. Она действует 5 минут и один раз. Обычный `/start` без ссылки создаёт отдельный Telegram-аккаунт. Уже существующие разные аккаунты автоматически не объединяются.

Старый webhook автоматически не удаляется. Сначала остановите прежний сервис и отключите webhook. При конфликте polling панель покажет ошибку. Проверка сервисов:

```bash
sudo bash scripts/health-check.sh
sudo docker compose ps
sudo docker compose logs --tail=50 bot
```

Меню, анимированное приветствие, Mini App, аккаунты, тарифы, заказы, Stars и просмотр подписок реализованы. Для Mini App задайте публичный `MINIAPP_URL`; он открывается кнопкой в меню бота. Live-соединение Telegram и ответ панели нужно проверить на вашей VPS после настройки настоящих токенов.

## ЮKassa и возвраты

1. Откройте **Оплата**, укажите Shop ID и секретный ключ ЮKassa. Секрет сохраняется только зашифрованным.
2. В кабинете ЮKassa укажите webhook: `https://ваш-домен/api/v1/payments/yookassa/webhook`. Платформа получает уведомление и дополнительно запрашивает платёж у ЮKassa перед активацией.
3. Включайте фискализацию только после проверки реквизитов: при включённом чеке у пользователя должен быть email, а `YOOKASSA_VAT_CODE` в `.env` должен соответствовать вашей налоговой схеме.
4. В **Тарифы** задайте цену Telegram Stars. В Telegram бот и Mini App используют эту цену и валюту `XTR`; доступ выдаётся только после `successful_payment`.

Раздел **Платежи** показывает подтверждённые и отменённые платежи. Возврат вызывает API соответствующего провайдера, меняет заказ на `refunded` и отзывает активную подписку.
