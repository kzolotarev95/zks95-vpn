Это обязательная часть проекта.

Создать установщик:

Создать обновление:

scripts/update.sh

Создать удаление:

scripts/uninstall.sh

Создать проверку:

scripts/health-check.sh

Установка должна выполняться на Ubuntu VPS.

Пример использования:

git clone https://github.com/kzolotarev95/zks95-vpn.git

cd zks95-vpn

cp .env.example .env

nano .env

chmod +x scripts/install.sh

sudo ./scripts/install.sh

4. Проверить необходимые порты.
5. Подготовить Docker-сети и volumes.
6. Собрать образы.
7. Запустить миграции.
8. Запустить контейнеры.
9. Проверить healthcheck.
10. Вывести адрес сайта и панели.
11. Вывести состояние Telegram Bot.
12. Вывести инструкции настройки HTTPS.

Не запрашивать пароли и секреты через Git.

Не записывать секреты в логи.
